Medora Events

Shows, concerts, races, history programs and festivals in Medora and the towns around it — from the Chateau de Morès to Dickinson and Watford City — gathered from local partners into one calendar and refreshed every day.

Subscribe

Add a feed to Apple Calendar, Google Calendar or Outlook and new events show up on their own. Feeds refresh every few hours.

Embed a widget

Pick a view and filters, then paste the snippet into any page. Browse gives visitors search, date and filter controls and keeps loading events as they scroll, all inside the embed. In Drupal, use the Full HTML text format (or paste the iframe version). The widget sizes itself to its content.


      
      
      

      
      
      

    

  






  
JSON API

  
Static JSON files, rebuilt on every run. No key needed; CORS is open. Every record carries the same fields — see Fields.

  

    
EndpointWhat it returns

    
      
/api/v1/events.jsonEvery upcoming occurrence, all fields (closures included, kind: "closure"). Also events.min.json.

      
/api/v1/upcoming.jsonNext 200 events with repeating tours collapsed to their next date (occurrences = count).

      
/api/v1/months/YYYY-MM.jsonEvents starting in one month.

      
/api/v1/sources/{id}.jsonOne organization's events plus its last-run status.

      
/api/v1/sources.jsonEvery source, when it last succeeded, event count and any error.

      
/api/v1/fields.jsonThe field dictionary.

      
/api/v1/review.jsonKeyword matches that may not be about TR, and dates read from prose — for staff review.

      
/api/v1/widget.jsonSlim index the widgets load.

Sources

  
Medora partners are included in full. Regional calendars (Dickinson State, Watford City, the Dickinson Press, ND Tourism, Facebook) are filtered to Medora and the towns around it. The same event posted in several places appears once.
